# Line Quality

## Desired character

The drawing should feel studied by hand: graphite or colored pencil on slightly warm paper, with thinking visible in the marks. It is precise enough to describe structure but never sterile.

## Contours

- Use a medium-dark structural contour with small pressure variation.
- Redraw selected edges once; keep the first attempt visible in places.
- Let joins land a fraction short or overshoot by a few millimeters.
- Make foreground contours marginally darker, not dramatically heavier.
- Avoid uniform digital strokes and perfectly closed shapes.

## Construction marks

- Extend selected perspective rays beyond the object.
- Retain centerlines, alignment checks, and faint box scaffolds.
- Use thin, low-contrast marks for provisional geometry.
- Erase selectively: leave pale ghosts where an earlier edge was corrected.
- Never cover the page with a grid; construction must serve a visible decision.

## Hatching

Use short, directional strokes that follow a plane's local orientation. Cross-hatch only at key recesses and overlaps. Preserve breathing room between clusters of marks.

## Avoid

No smooth airbrush gradients, ink-perfect vector outlines, generic sketch filters, or dense fuzzy scribble. Line variation should explain form, not simulate age.
