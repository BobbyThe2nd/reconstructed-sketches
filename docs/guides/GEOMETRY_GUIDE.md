# Geometry Guide

## Start with identity volumes

Strip the reference to the few volumes that make it recognizable. Buildings usually need a main mass, roof, entrance, and window rhythm. Objects need a body, opening, support, and one or two signature parts. Vehicles need a cabin/body split, wheels, and the gesture of the chassis.

## Primitive vocabulary

- **Cuboids / prisms:** rooms, cabinets, housings, seats, engines.
- **Wedges:** roofs, ramps, tool heads, tapered fronts.
- **Cylinders / discs:** wheels, knobs, legs, pipes, lamps.
- **Folded planes:** doors, hoods, awnings, thin extra faces.
- **Shallow curves:** only where a curve carries identity; otherwise facet it.

## Construction order

1. Place the bounding envelope and a centerline.
2. Draw the largest primary mass.
3. Add the three to five identity volumes.
4. Divide repeated rhythms: windows, drawers, spokes, shelves, panels.
5. Introduce selected perspective interventions only after the base reads clearly.
6. Remove all nonessential surface detail.

## Simplification rules

- Represent a row of many windows as three to six uneven modules.
- Convert reflections to a single tonal plane or omit them.
- Use one seam when it establishes a mechanical joint; discard decorative seams.
- Let circles become slightly irregular ellipses or faceted discs when that supports the drawing language.
- Keep edges structurally straight even when the projection is impossible.

## Extra-face construction

When adding an impossible face, begin with an ordinary edge. Offset it by a narrow plane, define its far boundary, and connect it to one established volume. Give it a distinct local convergence direction. This preserves the sensation of a model that has been reassembled rather than a distorted photograph.
