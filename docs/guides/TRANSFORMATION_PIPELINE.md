# Transformation Pipeline

## 1. Inspect

Identify the subject, its five most recognizable structural cues, and the incidental details that can be removed. Record the expected silhouette before drawing.

## 2. Choose a spatial thesis

Write a one-sentence decision: for example, “The house is reconstructed as three linked boxes whose roof and facade refuse the same horizon.” Choose a preset and a distortion budget.

## 3. Block geometry

Lay in the envelope, main mass, identity volumes, and repeated rhythm with light construction. At this stage, it should still read correctly with no shading.

## 4. Reconstruct perspective

Assign local edge systems, create one or more extra faces, and apply scale inversion where useful. Confirm that the strange relationships occur at planar seams, not as arbitrary warping.

## 5. Draw over the structure

Commit selective contours, retain chosen scaffolding, add double-drawn edges and correction ghosts. Delete only marks that make the volume unreadable.

## 6. Shade and color

Apply three-to-five value grouping, then a muted palette if desired. Keep paper dominant and planes distinct.

## 7. Review

Run the final test in [PERSPECTIVE_RULES.md](PERSPECTIVE_RULES.md) and reject outputs that violate [NEGATIVE_RULES.md](NEGATIVE_RULES.md). Check at both thumbnail and full size.

## Prompt scaffold

`Hand-drawn observational study of [subject], reconstructed from simple geometric volumes; [two selected perspective interventions]; visible graphite construction lines and selective redraw marks; [preset palette]; sparse plane-based hatching on warm paper; recognizable subject, generous blank background.`
