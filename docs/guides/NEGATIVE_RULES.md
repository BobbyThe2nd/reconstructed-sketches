# Negative Rules

## Do not allow

- Random or melted distortion that removes the subject's identity.
- A single perfect camera-perspective system when the brief calls for reconstruction.
- Every edge converging to arbitrary points without local plane logic.
- Extreme cubism, visual puzzles, or fragmented collage as a substitute for controlled extra faces.
- Photoreal materials, glossy reflections, depth-of-field blur, cinematic lighting, or rendered ambient occlusion.
- Smooth vector outlines, CAD precision, or uniform brush strokes.
- Neon colors, rainbow palettes, saturated plastic color, or dramatic gradients.
- Busy backgrounds, copied scenery, decorative texture overlays, or excessive paper distressing.
- Dense hatching that hides geometry.
- Unexplained duplicate parts that change what the subject is.

## Common corrections

| Failure | Correction |
| --- | --- |
| Looks accidental | Repeat the local rule in one neighboring edge and show a construction line. |
| Looks too realistic | Remove surface detail; expose scaffolding; flatten values. |
| Looks too abstract | Restore the silhouette, key opening/support, and repeated rhythm. |
| Looks digital | Add selective redraws, pencil grain, and uneven pressure—without fake noise. |
| Looks busy | Remove the background and halve the number of interior marks. |
